# PDF 全文解析・高速検索ツール (`aws_pdf_search`)

Windows向けにRustで構築した、**完全オフライン動作・単一実行ファイル**の高速PDF全文解析＆検索GUIアプリケーションです。
生成AIや外部API・ネットワーク通信を一切使用せず、純粋な統計自然言語処理（形態素解析・複合名詞抽出・コーパスTF-IDF・共起グラフ）と2次元レイアウト解析、および6特徴量ハイブリッド判断モデルによって、フォルダ内の全PDFから該当ページと根拠箇所を瞬時に特定します。

---

## 主な特徴

### 1. 2Dレイアウト＆日本語文章復元エンジン (`src/text_transcriber.rs`)
- `pdf_oxide` のSpan座標 `(x, y, width, height)`・フォントサイズ・アーティファクト属性を直接解析。
- **文中太字・色変更Spanの自然結合**: PowerPoint製PDFなどで文中の太字・色付き箇所の前後に入る不自然な改行を除去し、同一行として連結。
- **2Dテキストボックス・カラム別クラスタリング**: 左右に分かれた図解ボックスや段組みを別ブロックとして認識しつつ、同一ボックス内の右端折り返し（`データベー\nス`、`サー\nビスです。` など）を自然な1文に復元。
- **日英混在の空白正規化＆フッター除去**: 日本語助詞・句読点・括弧まわりの不自然な空白や、文末にくっつくページ番号・著作権フッターを自動除去。

### 2. 軽量ドキュメント解析モデル (`src/analyzer_model.rs`)
- **定型ヘッダー／フッター自動検出**: 各PDF内で35%以上のページに反復出現する行を統計的に自動検出してノイズ除去。
- **ページ見出し＆ページ種別（`PageRole`）の自動分類**: 各ページの見出し（`📌 タイトル`）を自動抽出し、`定義・解説` / `概要・まとめ` / `比較・一覧` / `図解・要点` / `問題・演習` / `表紙・扉` の6種別に自動分類。
- **複合名詞連結＋コーパスTF-IDF学習**: 連続する名詞から複合名詞（例：`責任共有モデル`、`可用性ゾーン`）を自動構築し、コーパス全体のIDF重要度と各ページの特徴重要語トップ6を算出。
- **共起語グラフ（関連キーワード推薦）**: 同一ページで共起しやすい専門用語を自動推薦（「💡 共起・関連語を追加」チップ）。

### 3. 6特徴量ハイブリッド判断モデル
検索クエリの意図（`概念・定義探索` / `比較・特徴・使い分け` / `条件・制限・構成確認` / `問題文・根拠特定` / `キーワード検索`）を自動判定し、以下の6特徴量から **判断ランク（`S` / `A` / `B` / `C`）と信頼度（`0〜99%`）** および **「🎯 最重要根拠文」** を算出します：
1. Tantivy BM25語彙スコア（見出し2.2倍ブースト）
2. IDF重み付き重要語カバー率
3. 同一文・近接出現スコア
4. ページ見出し一致ブースト
5. 複合名詞・フレーズ完全一致ブースト
6. クエリ意図とページ種別の適合度

### 4. 使いやすさ・高速UI (`src/app.rs`)
- **任意のPDFフォルダ対応＆ドラッグ＆ドロップ**: サブフォルダを含む任意のPDFフォルダを再帰スキャン。ウィンドウへのフォルダ／PDFドラッグ＆ドロップで即時切り替え。
- **フォルダ別独立キャッシュ**: `./cache/corpus_<hash>/` にインデックスと解析モデルを保存し、2回目以降は0.1秒以下で即座に検索可能。
- **3つの検索モード**:
  - `🧠 スマート解析・判断検索`（単語・短文・問題文コピペすべてに対応）
  - `🔍 通常検索`（AND/OR toggle、`"フレーズ"`、`-除外ワード`）
  - `🧩 部分一致 / 正規表現`
- **図解確認用PDFダイレクトジャンプ**: 「📄 このページをPDFで開く」ボタンで Microsoft Edge（または既定ブラウザ）の `#page=YY` へ直接ジャンプ。

---

## キーボードショートカット
- `Ctrl + K` / `Ctrl + F`: 検索ボックスに即フォーカス＋全選択
- `Esc`: 検索クエリをクリア
- `↑` / `↓`: 検索結果リストの選択移動

---

## ビルド・実行方法

```powershell
cargo build --release
.\target\release\aws_pdf_search.exe
```
（初回ビルド時は `build.rs` が公式の `mecab-ipadic` 辞書をコンパイルして実行ファイル単体に埋め込みます。ARM64 / x64 Windows の両方で `clang` 不要でネイティブビルド可能です）
